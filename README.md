# 🚀 Online Quiz Web App

A full-stack Java web application that allows users to take a timed quiz, calculates scores, and displays a leaderboard.

---

## 🎯 Features

- 👤 User enters name to start quiz
- ⏳ 60-second timer for quiz
- ❓ Multiple choice questions (MCQs)
- ✅ Automatic score calculation
- 🚫 One-time attempt restriction
- 🏆 Leaderboard (Top 5 users)
- 🎉 Animated result page (score counter + confetti)
- 📱 Mobile responsive UI
- 🎨 Modern UI with animations

---

## 🛠️ Tech Stack

- **Backend:** Java (Servlets, JSP)
- **Database:** MySQL
- **Connectivity:** JDBC
- **Frontend:** HTML, CSS, JavaScript
- **Server:** Apache Tomcat
